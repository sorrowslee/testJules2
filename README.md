# PixiJS Flappy Bird Game

A simple flappy bird style game built with PixiJS and TypeScript.

## Prerequisites

- Node.js and npm (or yarn)

## Setup

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```

## Development

To build the project and watch for changes, and serve it with live reload:
```bash
npm start
```
This will compile the TypeScript files and open the game in your default web browser.

## Manual Build

To just build the TypeScript files:
```bash
npm run build
```
This will output the compiled JavaScript to the `dist` directory.
